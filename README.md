# Chandu's Portfolio

A personal portfolio website introducing Chandu vanjangi, a first-year Computer Science student at Scaler School of Technology. The site highlights his background, skills, projects, education, and contact information.

## Project files

- `website.html` — the complete portfolio page, including its embedded CSS.
- `WhatsApp Image 2026-10-11 at 17.56.47 (2).jpeg` — the profile photo used in the hero section.

## Run locally

No build tools or dependencies are required. Open `website.html` in a web browser, or serve the project directory with any static web server.

## Features

- Responsive layout for desktop and mobile screens.
- Sticky navigation with a CSS-only mobile menu.
- Hero, about, skills, projects, education, and contact sections.
- Reduced-motion support for visitors who prefer less animation.
- Google Fonts (Bricolage Grotesque and Figtree); system fonts are used as fallbacks.

## Customization

Edit the content and embedded styles in `website.html`. The color palette and typography are defined near the top of its `<style>` block using CSS custom properties. Keep the profile image in the project directory or update the image path in the hero section if you move it.

Before publishing, review the project descriptions and links to ensure they point to the intended live demos and source repositories.
